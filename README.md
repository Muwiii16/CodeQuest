# CodeQuest

An AI-assisted educational tower-defense game for teaching introductory C to
first-year BSCS students, built with [libGDX](https://libgdx.com/) (Java 25) and
a Supabase backend. Students play campaign lessons and class tests; professors
manage sections, lessons, questions and class tests.

## First-time setup (needed on every computer)

The game talks to our Supabase project, and the connection details are **not** in
GitHub on purpose (`assets/supabase.properties` is gitignored). After cloning:

1. In the `assets/` folder, copy `supabase.properties.example` to a new file named
   `supabase.properties`.
2. Open it and fill in the project URL and the anon key (Supabase dashboard ->
   Project Settings -> API, or ask a teammate to send them privately).
3. Never commit that file or paste the key in public places.

Without it the game starts but every screen says "Supabase not configured".

You also need **JDK 25** installed (the Gradle wrapper does the rest).

## Running

```
./gradlew lwjgl3:run
```

On Windows PowerShell or cmd use `gradlew.bat lwjgl3:run`. Tests: `./gradlew core:test`.

## Accounts

- Students register on the login screen (Register tab, "I'm a student").
- Professors register with "I'm a professor" and need the professor access code. The
  code is checked on the server; ask the project owner for it (it is not kept in this repo).

## Structure

- `assets/`: placeholder art generated by `tools/GeneratePlaceholderAssets.java`
  (replace the PNGs with real art, same file names; paths are in `screens/Art.java`).
- `core/src/.../screens/`: every screen (login, student menus, gameplay, professor tools).
- `core/src/.../session/`: the pure game rules (run state, adaptive difficulty, ranks,
  class-test scoring, gacha odds and pity), unit tested.
- `core/src/.../content/`: question model and providers.
- `core/src/.../data/`: Supabase access (REST), caching and the local resume saves.
- `supabase/migrations/`: every database change, in order.
- `lwjgl3/`: the desktop launcher.
- `TODO.md`: what is done and what is still open.

## Gradle

This project uses [Gradle](https://gradle.org/); the wrapper is included, so use `gradlew.bat` or `./gradlew`.
Useful flags: `--continue`, `--offline`, `--refresh-dependencies`; tasks: `build`, `lwjgl3:run`, `core:test`.
